Dicas de Valores

  • a = 2, b = 0: Reta crescente passando exatamente pelo centro (origem).
  • a = -1, b = 5: Reta decrescente cruzando o eixo Y mais acima.
  • a = 0, b = 3: Reta horizontal (função constante).
  • a = 0.5, b = -4: Reta de inclinação suave, começando na parte inferior.
